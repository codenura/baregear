Commenting
==========

Commenting is needs for understanding code what code does For
Example You Wrote The Low Level Code For High Performance Then
You Keep The Code As Abandoned For Few Weeks Then You Improve
The Code To Commenting Is Needing To Understanding If Your
Code Has No Comment To Can Hard To Understand.

Single Line Comment:

.. code-block:: baregear

    # This Is Single Line Comment

Multiline Comment:

.. code-block:: baregear

    ---
    This Is Multiline Comment
    baregear ignores the comment
    ---

.. note::

   Don't Explain Easy To Understandable Logic Using Comment
   Because That Everyone Can Understand Without Comments Of
   Implemented Your Logic
